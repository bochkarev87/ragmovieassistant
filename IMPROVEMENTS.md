# Улучшения проекта

## 1. Векторная база (ChromaDB)

**Зачем:** Сейчас индекс хранится в файлах (vectorizer.pkl, matrix.npz). При росте датасета до 1000+ фильмов поиск будет медленным. ChromaDB даст быстрый поиск и масштабирование.

**Какие файлы менять:**
- `scripts/build_index.py` — вместо TF-IDF сохранять эмбеддинги в ChromaDB
- `app/retriever.py` — вместо загрузки файлов подключаться к ChromaDB

**Как проверить:** Замерить время поиска до/после. При 1000 фильмов скорость должна остаться высокой.

---

## 2. Embeddings вместо TF-IDF

**Зачем:** Сейчас поиск работает только по точному совпадению слов. Если пользователь спросит "картина про космос", а в тексте написано "фильм про космос" — не найдёт. Embeddings ищут по смыслу.

**Какие файлы менять:**
- `scripts/build_index.py` — добавить sentence-transformers для создания эмбеддингов
- `app/retriever.py` — использовать косинусное сходство между эмбеддингами запроса и чанков

**Как проверить:** Написать вопрос синонимами к описанию фильма. Сейчас не найдёт, после улучшения — найдёт.

---

## 3. Подключение LLM

**Зачем:** Сейчас ответ формируется простой склейкой фрагментов. LLM сможет пересказать ответ естественным языком, выделить главное, убрать повторы.

**Какие файлы менять:**
- `app/generator.py` — добавить вызов API (OpenAI или локальной модели)
- `app/prompts.py` — улучшить системный промпт

**Как проверить:** Сравнить ответы до и после. LLM должен давать более связный и читаемый ответ.
